切换存放位置不会移动已经存在的对象，地址一律按当前配置生成。换成对象存储之前，必须先把 uploads/ 下的文件按原路径同步进桶里（对象数应与 assets 表的行数一致），否则已有图片会全部失效；换回本地目录同理。两种位置只能有一个生效。

下面五项与两个凭据只在选择「对象存储」时必填；留在本地目录时可以先填好，日后切换不必重输。

S3 签名 API 地址。它不是公开读取面，浏览器不会访问它。

桶的公开读取地址：R2 自定义域名（推荐）或桶的 r2.dev 地址。图片地址由它生成，读者直接从该域名取图，不经过本站进程。

R2 用 auto 签名，留空即用默认值。

对象名在桶里的公共前缀，例如 uploads/ 或 blog/uploads，可留空。切换前缀会让已有对象失联，和切换存放位置一样需要先搬。

在 Cloudflare 控制台创建 R2 API Token（不要用全局 API Key），权限只需要 Object Read & Write 并限定到这一个桶。两个凭据只会加密保存，任何页面都不会回显，启动日志里也不会出现。
